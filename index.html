Inside the engineering +

The problem

Data dependencies make a small upstream change difficult to assess. Repeated investigations often duplicate the same work.

What I built

Downstream impact and upstream root-cause agents with a shared read/write adapter, GraphQL integration, and a FastAPI streaming interface.

The decision

Persist structured findings in DataHub itself. Separate catalog access from agent logic so investigations can use either the live integration or the in-memory demo.
