SenseCLLM

Protecting sensitive information
before it reaches the cloud.

Source code ↗AIIoT 2026 publication ↗

The problem

When an application sends raw text to a cloud model, sensitive information can leave the device before it is checked. SenseCLLM brings detection and protection onto the edge device.

The system

A three-agent PII detection pipeline that combines local language-model inference with adaptive pattern memory. Agents detect sensitive spans, learn patterns and protect text, then validate the output.

  1. 01

    Detect

    Identify sensitive information in incoming text.

  2. 02

    Learn & protect

    Generate and cache patterns, then selectively encrypt or abstract detected information.

  3. 03

    Validate

    Check privacy leakage, fluency, and over-encryption to guide the pipeline.

The engineering decision

Repeated patterns shouldn’t require repeated model work. The system caches LLM-generated regex patterns in adaptive memory, allowing later inputs to reuse what it has learned. A cache miss still needs new pattern generation; the fast path depends on what the system has seen before.

The result

Detection improved and latency fell together, because every learned pattern makes the next similar input cheaper. The figures above are reported evaluation results, not a guarantee for every input.

Under the hood

Python · Ollama · Three-agent orchestration · Adaptive pattern memory · Selective encryption
