Finding structure

Code & evaluation results ↗

The problem

Pathology reports contain valuable information in unstructured text. Classifying cancer types requires useful representations of clinical language and an evaluation that avoids misleading shortcuts.

What I built

A text-classification pipeline combining word- and character-level TF-IDF features with a Linear SVM. Clinical-term masking reduces direct diagnosis cues. I also extended the work to BioBERT for contextual representations.

The engineering decision

Keep evaluation separate from training. Split the reports before fitting vectorizers, and apply resampling only on the training data. Report the held-out SVM results separately from the BioBERT extension.

The result

94.5%Held-out accuracy
0.943Macro F1 across 32 classes

Results above belong to TF-IDF / Linear SVM on 1,905 held-out reports. BioBERT’s independent test evaluation remains pending.
